# 📝 Resume Pointers for NewsAI (BlogApp)

If you are adding this project to your resume, here are a few high-impact bullet points you can use. Tailor them based on the specific job you are applying for (e.g., more focus on AI for AI roles, more focus on backend for Backend roles).

### Option 1: Backend / Full-Stack Focus
* **Developed a full-stack Flask web application (NewsAI)** allowing users to create, manage, like, and report news posts, utilizing SQLAlchemy for robust database management.
* **Integrated Google's Gemini API** to implement an automated fact-checking system, analyzing user-submitted content to detect and flag potential misinformation.
* **Built a secure authentication system** using Flask-Login, bcrypt for password hashing, and integrated automated password-reset emails using Flask-Mail.
* **Designed a relational database schema** (SQLite/PostgreSQL) handling users, posts, likes, and reports, ensuring data integrity and efficient querying.

### Option 2: AI / Python Developer Focus
* **Engineered an AI-powered news verification platform** in Python (Flask) that validates user-submitted content for authenticity.
* **Utilized Google Generative AI (Gemini 2.5 Flash)** to process natural language from news posts and return a structured `true`/`false` veracity score.
* **Implemented secure backend architecture** including password hashing (bcrypt), token-based password resets, and session management (Flask-Login).
* **Deployed the application to Render**, ensuring responsive frontend interfaces and seamless backend AI inferences.

### Option 3: Short & Punchy (For constrained space)
* **NewsAI:** Built a Flask-based social platform with a Google Gemini AI integration to automatically fact-check and detect misinformation in user-generated news posts.
* Implemented secure user authentication (bcrypt, Flask-Login), email-based password resets, and complex database relationships (SQLAlchemy) for post interactions (likes/reports).
